# GitHub edge cases Shepherd handles

[← docs index](README.md) | [README](../README.md)

Each row is a PR state that a naive `gh` / GitHub MCP loop tends to misread, and what one Shepherd tick does about it. Links point to the spec section or to the recorded scenario under [`test-cases/fixtures/`](../test-cases/fixtures/). Each fixture directory is a named scenario. Its expected output is in [`test-cases/snapshots/`](../test-cases/snapshots/) under the same name.

The table describes what Shepherd surfaces and which action it picks. The agent still decides whether a surfaced item needs a code change.
